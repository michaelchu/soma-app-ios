# Soma iOS

Native iPhone app for Soma blood-pressure tracking (v1: BP only).

Mirrors the [Soma web app](https://github.com/michaelchu/soma): same dark theme, rose BP accent, bundled LINE Seed JP, and the same data and formats — metric card + 30-day bars + bulleted Insights + Recent Activity timeline (Today), category colour-block reading rows with PP/MAP (Readings), average-vs-previous + Detailed Statistics + Reference Ranges (Statistics), Timeline/Distribution charts with MAP/Trend/Markers toggles (Charts), and the same log form in a bottom sheet.

## Requirements

- Xcode 16+, iOS 17+
- An Apple Developer team selected in Xcode (Signing & Capabilities) — required for HealthKit
- The Soma API with token auth enabled (see `soma-api-auth/`)

## First run

1. Open `Soma.xcodeproj` in Xcode.
2. Select your development team under Signing & Capabilities.
3. If the fonts didn't come with the project copy, fetch them once:
   ```
   mkdir -p Soma/Resources/Fonts
   curl -o Soma/Resources/Fonts/LINESeedJP-Regular.ttf https://fonts.gstatic.com/s/lineseedjp/v6/MwQxbh7r89it6QsEXfZb-jMfjQ.ttf
   curl -o Soma/Resources/Fonts/LINESeedJP-Bold.ttf https://fonts.gstatic.com/s/lineseedjp/v6/MwQubh7r89it6QsEXfZb-jMnMbRurQ.ttf
   ```
   (LINE Seed JP, Google Fonts — same files the web app loads.)
4. Run on your iPhone.
5. On first launch, enter your Soma API base URL (e.g. `https://your-app.vercel.app`) and API token, then tap Done. The token is stored in the Keychain.
6. In Settings you can connect Apple Health (two-way sync) and set the daily reminder time.

## Project layout

```
Soma/
  SomaApp.swift            App entry
  Theme/SomaTheme.swift    Colours (web index.css tokens) + LINE Seed JP
  Models/BPModels.swift    Sessions, HTN Canada 2025 categories, stats,
                           date ranges, change indicators (ported from web)
  API/SomaAPIClient.swift  REST client (bearer token from Keychain)
  API/KeychainHelper.swift Token storage
  State/BPStore.swift      Sessions state: load / log / delete / Health sync
  State/FilterState.swift  Shared W/M/Q/All + time-of-day filter
  HealthKit/HealthKitManager.swift  Two-way HealthKit sync
  Notifications/ReminderManager.swift  Daily local reminder
  Views/                   Today / Readings / Statistics / Charts /
                           QuickLogSheet / Settings / ContentView
  Resources/Fonts/         LINE Seed JP (Google Fonts, OFL)
  Info.plist, Soma.entitlements (HealthKit)
```

## Notes

- `Soma.xcodeproj/project.pbxproj` is generated by `generate_project.py` (run it again if you add files).
- HealthKit: share authorization is requested only for the systolic/diastolic/heart-rate quantity types — never for the BP correlation type (requesting it throws `NSInvalidArgumentException`; this bit us in the importer).
- New readings are written to HealthKit as BP correlations; the Settings screen can import HealthKit readings missing from Soma (deduped by date + values).
